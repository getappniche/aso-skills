# Contributing

Improvements to skill playbooks are welcome — sharper workflows, better output
formats, tighter guardrails.

1. Fork, branch, edit.
2. Keep the SKILL.md format (see AGENTS.md): frontmatter `name` matches the
   folder, `description` ends with a "Use when …" trigger.
3. Only reference the seven real MCP tools — no invented endpoints.
4. Run `./validate-skills.sh` — it must pass.
5. Open a PR with a one-paragraph "what changed and why".

Bug in the data or the hosted server? That's not this repo — email
yaro@getappniche.com or use the dashboard at app.getappniche.com.
